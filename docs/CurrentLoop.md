# 4〜20mA（電流ループ）の受け方

⚠️ **このページは必ず読んでください。読まずに配線すると基板を壊します。**

## 抵抗1本で受けてはいけない

ネットには「250Ωの抵抗を挟めば1〜5Vになる」と書かれています。**このシステムでそれをやってはいけません。**

4〜20mAのセンサーは **DC24V** のループ電源で動きます。つまり、その配線には常に24Vが乗っています。

- 抵抗が外れる・浮く・接触不良を起こすと、電流源は電圧を上げきります。**入力に24Vがそのまま掛かります**
- [ADS1115](./ADS1115.md) の上限は5.3V。**一瞬で壊れます。しかも基板ごと道連れになります**
- ループ側とマイコン側のGNDが繋がるので、電位差があれば電流が回り込みます（グラウンドループ）
- 配線を1本間違えただけで、24Vが直撃します

抵抗1本の節約と、基板・マイコン・PCのUSBポートを引き換えにする価値はありません。

## 正解：ディストリビュータ（信号変換器）を挟む

**ディストリビュータ**は、4〜20mAを受けて **1〜5V などの電圧に変換して出す**専用機器です。多くは入出力間が絶縁されているので、24Vの世界とマイコンの世界が電気的に切り離されます。

- 24Vが入力側に回り込まない（**絶縁が壁になる**）
- センサー用のDC24V電源を供給してくれるタイプもある
- ノイズ対策としても効く

```
[4-20mAセンサー] ──24Vループ──> [ディストリビュータ] ──1〜5V──> [ADS1115 / AI8〜15]
                                    ↑ここで絶縁される
```

## 買い方

**ミスミ（MISUMI）で「ディストリビュータ」「信号変換器」と検索すれば安いものが買えます。** 高機能なものを選ぶ必要はありません。見るのは次の2点だけです。

| 見るところ | 選ぶもの |
| --- | --- |
| 出力 | **1〜5V**（そのまま [ADS1115](./ADS1115.md) に入る）。0〜10V品なら分圧が必要 |
| 絶縁 | **絶縁形**を選ぶ。これが安全の本体です |

DINレールに付く手のひらサイズの箱です。**4〜20mAのセンサーを使うなら、これは必須の部品だと思ってください。**

## 4〜20mAという規格は悪くない

むしろ優秀です。電流で送るので電圧降下やノイズの影響を受けず、0mAが「断線」を意味するので故障も検知できます。工場で長く使われてきた理由があります。

悪いのは規格ではなく、**受け方**です。センサー側は4〜20mAのままでよいので、受ける側で必ず絶縁変換してください。
