# 同軸ケーブル・BNC・50Ω

計測器の世界でよく見かける道具の話です。**知らずに真似すると損をする**ポイントがあります。

## 同軸ケーブルとは

芯線を絶縁体で包み、その外を網（シールド）で筒状に覆った構造のケーブルです。

- 芯線が完全に囲まれているので、**シールド効果が高い**
- 形が一定なので、電気的な性質が全長で揃う
- 外側の網はGNDに繋がる（→ [Shield.md](./Shield.md)）

## BNCコネクタ

同軸を挿してひねるだけで着脱できるコネクタです（バヨネット式）。

- 片手で確実に着脱でき、緩みにくい
- オシロスコープ、チャージアンプ、加速度センサー、LVDTの変換器などで定番
- **外側の金属＝GND**。BNC機器を複数繋ぐと、そこでGNDが共通化されます

> ⚠️ 複数のBNC機器を繋ぐと、意図せず**グラウンドループ**ができます。ノイズが増えたらここを疑ってください（→ [Shield.md](./Shield.md)）

## 「50Ω」は抵抗値ではない

いちばん誤解されるところです。**テスターで測っても50Ωにはなりません**（芯線とシールドの間は絶縁されているので∞、芯線どうしはほぼ0Ω）。

これは**特性インピーダンス**といって、「高周波の信号がケーブルを進むときの流れやすさ」を表す値です。

| 種類 | 主な用途 |
| --- | --- |
| 50Ω | 計測器・無線。オシロやRF機器はこちら |
| 75Ω | 映像・アンテナ |

送り出す機器・ケーブル・受ける機器の3つが揃っていないと、信号が境目で跳ね返って（反射して）波形が乱れます。

## ただし、本システムでは関係ない

反射が問題になるのは、**信号がケーブルを往復する時間が無視できない速さ**のとき——ナノ秒〜MHzの世界です。

本システムが測るのは、10回/秒のロードセルや、ゆっくり動く変位計。**50Ωか75Ωかは実用上どうでもいい**話です。手元にある方を使ってください。

代わりに効いてくるのはこちらです。

- **ケーブルの静電容量**（同軸はおよそ100pF/m）。ハイインピーダンスの信号に長い同軸を使うと、応答が鈍ります
- **長さ**。短いほど良い、は変わりません

## 本システムにつなぐとき

基板側は**端子台（ネジ止め）**です。BNCで出てくる機器を繋ぐなら、BNC-端子台の変換ケーブルか、BNCコネクタ付きの中継箱を用意することになります。

| コネクタ | 性格 |
| --- | --- |
| 端子台 | 安価・自由。ただし**振動で緩む**ので定期確認を |
| BNC | 着脱が速く確実。計測器向き |
| M12などのネジ式丸型 | 現場向き。防水・振動に強い |

## 初心者向けの注意

- 圧着端子は**専用工具**で。ペンチで潰したものは、後で必ず接触不良になります
- 同軸を鋭角に曲げない。中の構造が崩れると特性が変わります
- 4〜20mAの機器をBNCで受けても危険性は変わりません。必ず[ディストリビュータ](./CurrentLoop.md)を挟んでください
