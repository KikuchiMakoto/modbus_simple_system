# ADS1115とは
電圧入力型のアナログデジタル変換器（ADC）である

（全装置のGNDを一緒にする）シングルエンド動作想定なので、マイナスの電圧は測れません。

入力電圧の上限はArduino電圧の+0.3Vまでなので、5.3Vが上限です。
（マイコンからADS1115に供給される電圧、つまりはI2C通信電圧とも言える）

1つのICに4chの入力がありますが、変換器は4個なので、1chずつ（逐次）変換することになります。

## ざっくり仕様

| 項目 | 内容 |
| --- | --- |
| 分解能 | 16bit |
| 入力 | 4ch（シングルエンド） |
| 接続 | I2C（→ [I2C.md](./I2C.md)） |
| 変換速度 | 8〜860回/秒（設定で変更） |
| レンジ設定 | 内蔵アンプ（PGA）で最大 ±6.144V まで選択可 |

本システムでは **AI8〜AI15** の8chがADS1115です（IC 2個 × 4ch）。

## レンジ（PGA）の考え方

レンジは「何Vまで測るか」の設定です。狭くするほど細かく読めます。

- ±6.144V を選んでも、**実際に入れてよいのは5.3Vまで**（電源電圧＋0.3V）
- 0〜5Vのセンサーなら ±6.144V、0〜1Vの微小信号なら ±1.024V、というふうに信号に合わせて選ぶ
- レンジを超えた入力は頭打ち（サチる）ので、グラフが平らになったら疑う

## 10Vなどを分圧して入れるときの鉄則

上限5.3Vなので、0〜10V出力の装置は抵抗2本で分圧して半分にしてから入れます。ここには**守るべき数字と、やってはいけないこと**があります。

### ① 分圧全体に 5〜10mA 流れるように設計する

分圧抵抗は、送り出す装置から見れば「負荷」です。**その電流を出せる装置にしか繋げません。**

```
合計抵抗 = 出力電圧 ÷ 流したい電流
```

| 合計電流 | 合計抵抗 | 1/2分圧の構成 | 各抵抗の消費電力 |
| --- | --- | --- | --- |
| 5mA | 2kΩ | 1kΩ ＋ 1kΩ | 約25mW |
| 10mA | 1kΩ | 510Ω ＋ 510Ω | 約50mW |

抵抗は1/4W品で足ります。

**なぜ大きめの電流を流すのか：**

- ADS1115の入力は完全なハイインピーダンスではなく、**内部でわずかに電流を引きます**。分圧側のインピーダンスが高いと、その分だけ電圧が下がって誤差になります
- 低いインピーダンスほど**ノイズを拾いません**。ハイインピーダンス配線はアンテナになります

**その代わり、条件があります：**

> ⚠️ **10mA近くを出せる装置限定です。** 使う前に必ず装置の仕様書で「出力電流」「負荷抵抗」を確認してください。出せない装置に繋ぐと出力電圧が垂れて測定値が狂い、最悪、相手を壊します。

### ② 途中にコンデンサ・コイルを絶対に入れない

ノイズ対策のつもりで、分圧に**コンデンサを足したくなったら手を止めてください。**

- 相手の**駆動力（電流を出す能力）が食われます**。容量負荷は装置側のアンプにとって最悪の相手で、応答が鈍る・波形が鈍る・機種によっては**発振します**
- コイルは論外。抵抗と組み合わさって**共振（RLC）**します。特定の周波数で電圧が跳ね上がり、何を測っているのか分からなくなります
- 抵抗とコンデンサでローパスフィルタになるので、**測りたい現象そのものが遅れて記録されます**。しかも「なんとなく安定して見える」ので、間違いに気づけません

> **RLC（抵抗・コイル・コンデンサ）が回路の中でどう振る舞うか説明できないなら、抵抗以外を絶対に足さないこと。**
> 下手にいじるくらいなら、抵抗2本だけの方が正確に測れます。ノイズが気になるなら、まず配線を短くし、GNDを共通にし、動力線から離してください。順番はそれからです。

## 初心者向けの注意

- **GNDは必ず全部つなぐ**。GNDが浮くと値がふらつきます
- 4chを順番に変換するため、chを増やすほど1chあたりの更新は遅くなります
- I2Cアドレスは4種類から選べます。IC 2個が同じアドレスだと両方読めません
- マイナス電圧・大きい電圧を測りたいときは、抵抗分圧やレベルシフト回路が別途必要です（分圧は上記の鉄則を守ること）
- ⚠️ **4〜20mAのセンサーを抵抗1本で受けてはいけません。** 配線にはDC24Vが乗っており、抵抗が浮いた瞬間に24Vが入力に直撃して壊れます。**絶縁形のディストリビュータ（信号変換器）で1〜5Vに変換してから**入れてください（→ [CurrentLoop.md](./CurrentLoop.md)）
