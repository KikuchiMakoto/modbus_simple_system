# ADS1115とは
電圧入力型のアナログデジタル変換器（ADC）である

（全装置のGNDを一緒にする）シングルエンド動作想定なので、マイナスの電圧は測れません。

入力電圧の上限はArduino電圧の+0.3Vまでなので、5.3Vが上限です。
（マイコンからADS1115に供給される電圧、つまりはI2C通信電圧とも言える）

1つのICに4chの入力がありますが、AD変換器は1個なので、4chを1chずつ（逐次）切り替えて変換します。

## ざっくり仕様

| 項目 | 内容 |
| --- | --- |
| 分解能 | 16bit |
| 入力 | 4ch（シングルエンド） |
| 接続 | I2C（→ [I2C.md](./I2C.md)） |
| 変換速度 | **本システムでは128回/秒に固定**（IC自体は8〜860回/秒で設定可だが、ファームウェアが128SPSに固定している。変更にはファーム改修が必要） |
| レンジ設定 | 内蔵アンプ（PGA）。**本システムでは±6.144Vに固定** |

本システムでは **AI8〜AI15** の8chがADS1115です（IC 2個 × 4ch）。

## レンジ（PGA）の考え方

レンジは「何Vまで測るか」の設定です。狭くするほど細かく読めます。

- IC自体は±0.256V〜±6.144Vの6段階から選べるが、**本システム（ファームウェア）は±6.144Vに固定**している。レンジを変えたい場合もファーム改修が必要
- ±6.144V を選んでも、**実際に入れてよいのは5.3Vまで**（電源電圧＋0.3V）
- レンジを超えた入力は頭打ち（サチる）ので、グラフが平らになったら疑う

## 10Vなどを分圧して入れるときの鉄則

**分圧抵抗は諸刃の剣です。** 測れるレンジを広げてくれる代わりに、その意味とデメリットを理解して正しく実装しないと、ありとあらゆる安定性（ノイズ耐性・精度・応答性）を失い、最後にはADS1115そのものを壊します。「とりあえず抵抗2本挟めばいい」という発想では扱ってはいけません。

> ⚠️ **抵抗分圧は本来おすすめしません。** 配線を間違えると、分圧される前の10Vがそのままマイコン基板（[ArduinoNanoR4](./ArduinoNanoR4.md)）を直撃し、ADS1115だけでなくマイコンごと壊れます。**これはどうしても他に手段がないときだけの対処**です。
>
> 基本は**5V以下に変換してから入れる**こと。[CurrentLoop.md](./CurrentLoop.md) で紹介している**絶縁形の信号変換器（ディストリビュータ）**は0〜10V→0〜5Vなどの電圧変換品も多数あります。ミスミなどで探せば見つかるので、まずはそちらを検討してください。絶縁されていれば、10V側の配線ミスがマイコン側に伝わりません。
>
> それでも抵抗分圧しか選べない場合のみ、以下を守ってください。**守るべき数字と、やってはいけないこと**があります。

上限5.3Vなので、0〜10V出力の装置は抵抗2本で分圧して半分にしてから入れます。

### ① 分圧全体に 5〜10mA 流れるように設計する

分圧抵抗は、送り出す装置から見れば「負荷」です。**その電流を出せる装置にしか繋げません。**

```
合計抵抗 = 出力電圧 ÷ 流したい電流
```

| 合計電流 | 合計抵抗 | 1/2分圧の構成 | 各抵抗の消費電力 |
| --- | --- | --- | --- |
| 5mA | 2kΩ | 1kΩ ＋ 1kΩ | 約25mW |
| 10mA | 1kΩ | 510Ω ＋ 510Ω | 約50mW |

抵抗は1/4W品で足ります。

**なぜ大きめの電流を流すのか：**

- ADS1115の入力は完全なハイインピーダンスではなく、**内部でわずかに電流を引きます**。分圧側のインピーダンスが高いと、その分だけ電圧が下がって誤差になります
- 低いインピーダンスほど**ノイズを拾いません**。ハイインピーダンス配線はアンテナになります

**その代わり、条件があります：**

> ⚠️ **10mA近くを出せる装置限定です。** 使う前に必ず装置の仕様書で「出力電流」「負荷抵抗」を確認してください。出せない装置に繋ぐと出力電圧が垂れて測定値が狂い、最悪、相手を壊します。

**相手がそこまで電流を出せない場合：**

10kΩ＋10kΩ（合計20kΩ、電流0.5mA程度）まで抵抗値を上げても、ADS1115の入力インピーダンスを考慮した誤差は0.1%程度に収まります。電流を出せない装置につなぐしかない場合の妥協案として使えますが、あくまで理想は①の5〜10mA構成です。低電流構成にするほど配線がノイズを拾いやすくなる点は変わらないので、配線を短くする・GNDを共通にするといった基本対策は必須です。

**抵抗自体の精度にも注意してください。** 分圧比は抵抗の誤差がそのまま測定誤差になります。誤差1%以下、できれば**0.1%以下の高精度抵抗器**を使ってください。安価な誤差5%品などを2本組み合わせると、分圧比自体が最大で数%ずれることがあります。

### ② 途中にコンデンサ・コイルを絶対に入れない

ノイズ対策のつもりで、分圧に**コンデンサを足したくなったら手を止めてください。**

- 相手の**駆動力（電流を出す能力）が食われます**。容量負荷は装置側のアンプにとって最悪の相手で、応答が鈍る・波形が鈍る・機種によっては**発振します**
- コイルは論外。抵抗と組み合わさって**共振（RLC）**します。特定の周波数で電圧が跳ね上がり、何を測っているのか分からなくなります
- 抵抗とコンデンサでローパスフィルタになるので、**測りたい現象そのものが遅れて記録されます**。しかも「なんとなく安定して見える」ので、間違いに気づけません

> **RLC（抵抗・コイル・コンデンサ）が回路の中でどう振る舞うか説明できないなら、抵抗以外を絶対に足さないこと。**
> 下手にいじるくらいなら、抵抗2本だけの方が正確に測れます。ノイズが気になるなら、まず配線を短くし、GNDを共通にし、動力線から離してください。順番はそれからです。

## 初心者向けの注意

- **GNDは必ず全部つなぐ**。GNDが浮くと値がふらつきます
- 4chを順番に変換するため、chを増やすほど1chあたりの更新は遅くなります
- I2Cアドレスは4種類から選べます。IC 2個が同じアドレスだと両方読めません
- マイナス電圧・大きい電圧を測りたいときは、絶縁信号変換器やレベルシフト回路が別途必要です（抵抗分圧する場合は上記の鉄則を守ること）
- ⚠️ **4〜20mAのセンサーを抵抗1本で受けてはいけません。** 配線にはDC24Vが乗っており、抵抗が浮いた瞬間に24Vが入力に直撃して壊れます。**絶縁形のディストリビュータ（信号変換器）で1〜5Vに変換してから**入れてください（→ [CurrentLoop.md](./CurrentLoop.md)）
