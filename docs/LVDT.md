# LVDT（差動トランス式変位計）とは

コイルの中を鉄心（コア）が動くことで変位を測るセンサーです。**触れずに測る**ので摩耗せず、材料試験の変位計として定番です。

## しくみ

1次コイルに数kHzの交流を流し、その外側に2次コイルを2つ、**逆向きに直列（差動）**でつなぎます。

- コアが中央 → 2つの誘起電圧が等しく打ち消し合い、**出力ゼロ**
- コアがずれる → 差が出る。**振幅＝移動量、位相＝どちら向きか**

中心をまたぐと位相が180°反転するので、正負の向きが分かります。

## 2種類ある（ここが重要）

| 型 | 出力 | 本システムでの扱い |
| --- | --- | --- |
| **AC-AC**（生のLVDT） | 交流 | 励起・復調器が別途必要。**直結できません** |
| **DC-DC**（発振・復調回路を内蔵） | 直流（±10V、0〜10V、4〜20mA など） | [ADS1115](./ADS1115.md) 側（AI8〜15）へ。ただし下記の制限あり |

自作システムにつなぐなら **DC-DC型を選ぶ**のが前提です。

## 本システムにつなぐときの注意

ADS1115の入力は **0〜5.3V、マイナス不可**。ここが最大の関門です。

| センサー出力 | 対応 |
| --- | --- |
| 0〜5V | そのまま入る（おすすめ） |
| 0〜10V | 抵抗で1/2以下に分圧して入れる |
| ±10V | 分圧＋オフセット回路が必要。素直に単極性出力の機種を選ぶ方が楽 |
| 4〜20mA | 250Ωの抵抗を挟めば 1〜5V に化ける。GNDは共通に |

> 🔰 ひずみゲージ式のクリップ式伸び計（エクステンソメータ）なら、ブリッジなので **HX711側（AI0〜7）にそのまま入ります**。変位計を新規に買うなら、こちらの方が本システムとは相性が良いです。

## 長所と短所

**長所**：摩耗部がなく寿命が長い／分解能が細かい／振動・汚れに強い／出力が大きい

**短所**：高価／AC励起が要る（DC-DC型は内蔵）／コアと本体の芯出しが必要／可動部の質量ぶん、速い動きには弱い

## 初心者向けの注意

- コアが可動範囲の端に来ると直線性が崩れます。**中央付近を使う**ようにセットする
- コアとボビンが擦れていないか確認。接触すると摩耗し、値も暴れます
- 変位が「向きだけ逆」なら、[校正](./Calibration.md)の係数の符号で合わせられます
- 交流励起の背景は [Excitation.md](./Excitation.md) を参照
