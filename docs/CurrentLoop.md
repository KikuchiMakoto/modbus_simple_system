# 4〜20mA（電流ループ）の受け方

⚠️ **このページは必ず読んでください。読まずに配線すると基板を壊します。**

> 🔰 4〜20mA＝「測定値0のとき4mA、最大のとき20mA」と**電流の大きさで値を送る**産業標準の信号方式。土質試験機や現場計測のセンサーでよく使われます。

## 抵抗1本で受けてはいけない

ネットには「250Ωの抵抗を挟めば1〜5Vになる」と書かれています。**このシステムでそれをやってはいけません。**

4〜20mAのセンサーは **DC24V** のループ電源で動きます。つまり、その配線には常に24Vが乗っています。

- 抵抗が外れる・浮く・接触不良を起こすと、電流源は電圧を上げきります。**入力に24Vがそのまま掛かります**
- [ADS1115](./ADS1115.md) の上限は5.3V。**一瞬で壊れます。しかも基板ごと道連れになります**
- ループ側とマイコン側のGNDが繋がるので、電位差があれば電流が回り込みます（グラウンドループ）
- 配線を1本間違えただけで、24Vが直撃します

抵抗1本の節約と、基板・マイコン・PCのUSBポートを引き換えにする価値はありません。

## 正解：ディストリビュータ（信号変換器）を挟む

**ディストリビュータ**は、4〜20mAを受けて **1〜5V などの電圧に変換して出す**専用機器です。多くは入出力間が絶縁されているので、24Vの世界とマイコンの世界が電気的に切り離されます。

- 24Vが入力側に回り込まない（**絶縁が壁になる**）
- センサー用のDC24V電源を供給してくれるタイプもある
- ノイズ対策としても効く

```
[4-20mAセンサー] ──24Vループ──> [ディストリビュータ] ──1〜5V──> [ADS1115 / AI8〜15]
                                    ↑ここで絶縁される
```

## 買い方

**ミスミ（MISUMI）で「ディストリビュータ」「信号変換器」と検索すれば安いものが買えます。** 高機能なものを選ぶ必要はありません。見るのは次の2点だけです。

| 見るところ | 選ぶもの |
| --- | --- |
| 出力 | **1〜5V**（そのまま [ADS1115](./ADS1115.md) に入る）。0〜10V品なら分圧が必要 |
| 絶縁 | **絶縁形**を選ぶ。これが安全の本体です |

DINレールに付く手のひらサイズの箱です。**4〜20mAのセンサーを使うなら、これは必須の部品だと思ってください。**

## そもそも、なぜ電流で送るのか

規格自体はとても優秀です。**電圧より圧倒的に強い**理由が3つあります。

### ① 長い配線でも値が変わらない

電圧で送ると、配線の抵抗で電圧が下がります。100m引けばその分だけ低く読めてしまう。

電流は違います。**1本の輪（ループ）の中では、どこを測っても電流は同じ**です（キルヒホッフの法則）。配線が10mでも500mでも、流れる電流は変わりません。

> 電圧信号は「配線が長いと値がずれる」。電流信号は「ずれようがない」。

### ② ノイズに強い

電流ループは**低いインピーダンス**の回路です。外から電磁誘導でノイズが飛び込んできても、低インピーダンスの回路では電圧として育たず、握りつぶされます。

一方、電圧信号をハイインピーダンスで受けると、配線がアンテナになってノイズをそのまま拾います。工場のインバータやモーターの近くでは、この差が決定的です。

### ③ 0mAで故障が分かる（ライブゼロ）

これが最大の利点です。**測定値の0を、あえて4mAに割り当てている**（ライブゼロ）ので、0mAは「あり得ない値」になります。

| 電流 | 意味 |
| --- | --- |
| **0mA** | **断線・電源断・センサー故障** |
| 4mA | 測定値 0%（正常な下限） |
| 20mA | 測定値 100%（正常な上限） |
| 20mAより大きい | 過大入力・異常 |

0〜10Vの電圧信号だと、「本当に0だった」のか「線が抜けた」のか**区別できません**。試験が終わってデータを見て、ずっと0だったことに気づく——という事故が起きます。

4〜20mAならその場で分かります。3.6mA以下・21mA以上を異常と判定する運用もあります（NAMUR NE43）。

### おまけ：2線式なら電源も兼ねる

センサーが4mA未満で動く設計なら、**信号線がそのまま電源線**になります。現場まで2本引くだけで済むので、配線が激減します。

---

つまり、悪いのは規格ではなく **受け方** です。センサー側は4〜20mAのままでよいので、受ける側で必ず絶縁変換してください。
