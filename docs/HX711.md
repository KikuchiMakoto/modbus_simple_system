# HX711とは
ひずみアンプを搭載したアナログデジタル変換器（ADC）である

ロードセルの出力はとても小さい（フルスケールで数mV。mV＝1/1000 V）ので、そのままでは測れません。HX711は「増幅」（小さな信号を大きくすること）と「AD変換」（電圧を数字にすること）を1個のICでやってくれます。

> 🔰 「ひずみアンプ」「ブリッジ」という言葉が出てきたら [StrainGauge.md](./StrainGauge.md)、ロードセル自体は [LoadCell.md](./LoadCell.md) に説明があります。

## ざっくり仕様

| 項目 | 内容 |
| --- | --- |
| 分解能 | 24bit |
| 内蔵アンプ | ゲイン 128 / 64 倍（chA）、32倍（chB） |
| 給電（励起）電圧 | 約4.2V（IC内部で生成） |
| 変換速度 | 10回/秒（市販モジュールは実質これ固定）または 80回/秒 |
| 接続 | 専用の2線（クロックとデータ）。I2CでもSPIでもない |

本システムでは **AI0〜AI7** の8chがHX711です（1chにつきIC1個）。

## つなぎ方（4線式ロードセル）

| HX711側 | ロードセル線色（一般例） | 意味 |
| --- | --- | --- |
| E+ | 赤 | ブリッジへの給電＋ |
| E− | 黒 | 給電− |
| A+ | 緑 | 信号＋ |
| A− | 白 | 信号− |

色は製品によって違います。**必ずロードセルの仕様書を確認**してください。

## 給電（励起）電圧は5Vではなく約4.2V

E+ に出る電圧は、HX711が内部レギュレータと分圧抵抗で作った **約4.2V** です。USBの5Vがそのまま出ているわけではありません。

100kg / 2.0mV/V のロードセルなら、定格100kgを掛けたときの信号は

```
4.2V × 2.0mV/V ＝ 約8.4mV
```

電圧から物理値を計算するときは、5Vではなくこの4.2Vを使います。

## 入力レンジは「mV/V」で考える

HX711のフルスケールは `±0.5 × 給電電圧 ÷ ゲイン`。給電電圧で割ると電源によらない一定値になるので、**ロードセルの mV/V とそのまま比べられます**。

| ゲイン | 使えるch | フルスケール | 4.2V給電時 |
| --- | --- | --- | --- |
| 128 | A | ±3.906 mV/V | 約 ±16.4mV |
| 64 | A | ±7.813 mV/V | 約 ±32.8mV |
| 32 | B | ±15.63 mV/V | 約 ±65.6mV |

つまりゲイン128でも、**2.0mV/V のロードセルは定格でレンジの半分しか使いません**。

- 良い面：定格の約2倍まで振っても数値は振り切らない（ロードセル自体は壊れるので推奨はしません）
- 悪い面：24bitのうち半分を捨てているのと同じ。とはいえ元が24bitなので実用上は十分です

## 80SPSは速いが精度が落ちる

変換速度は RATE ピンで 10SPS / 80SPS を切り替えます。

- 市販のHX711モジュールは RATE ピンがGNDに直結されていて、**実質10SPS固定**です（80SPSにするには基板の改造が必要）
- 10SPSのときは内部フィルタが **50/60Hz（商用電源のノイズ）を落としてくれます**。80SPSではこの効果がなくなります
- ノイズそのものも増えるため、実効分解能（実際に信じられる桁数）が数bit分落ちます

本システムは計測アプリのポーリングが100ms固定なので、**10SPSで足ります**。速さより安定を取る設定です。

## DOUTは「好きなタイミングで読んでいい」わけではない

**ありがちな勘違い**：HX711は準備ができたら、あとは好きなタイミングで24bitデータを読みに行けばよい、というものです。**これは誤りです。**

HX711は変換が終わるとDOUTピンをLowに落として「データ準備完了（ready）」を知らせます。ここでクロックを叩いて読み出すわけですが、**読み出しが遅れて次の変換周期（10SPSなら約100ms、個体差で実際は80〜100ms程度のものが多い）に被ると、不定値が読み出されます。**

当たり前の話です。フードコートで「できました」の札を出したのに、いつまでも取りに来ない客を待ってはくれません。DOUTをLowにして知らせた以上、取りに来ないほうが悪いのです。**HX711は「定期的に律儀に読みに行き続けなければいけない」ADコンバータ**であって、好きなときに覗き見できるレジスタではありません。

- 推奨：readyを**割り込み**で検知して即座に読む
- 許容：どんなに遅くとも周期の10%（10SPS＝約100ms周期なら**10ms以内**）
- 最悪でも：周期の50%（**50ms以内**）。これを超えて次周期に被ると、不定値のリスクが上がる

なぜこう言い切れるかというと、データシートのどこにも「readyになった後は自由なタイミングで読んでよい」とは書かれていないからです。書かれていない＝**未定義動作**。読み出しが遅れる使い方自体、開発者は想定していないと読むべきです。

> 🔰 ここまでArduinoで気軽に使われるとは、設計時点では想定していなかったのかもしれません。ポーリングを疎かにするコードは、データシートが定義していない領域に踏み込んでいます。

## 秋月電子のHX711モジュールを使うときは

本システムで使う定番モジュールですが、**割り切った作り**なので先に把握しておいてください。

| 項目 | 実際 |
| --- | --- |
| 電源 | **5Vシステム専用**。3.3Vのマイコンでは動きません |
| ゲージ励起電圧 | **4.2V固定**（変更不可） |
| 変換速度 | **10SPS固定**。80SPSには変えられません |
| シールド端子 | **ありません** |

いずれも制約というより「材料試験の用途にはこれで十分」という割り切りです。[Arduino Nano R4](./ArduinoNanoR4.md) が5V系なので、電源の相性も問題ありません。

### シールド線をどう繋ぐか

専用の端子台がないので、**ロードセルのシールド線は E−（給電−）に落としてください。**

- 落とすのは**片側だけ**。センサー側と基板側の両方で接地すると、かえってノイズが増えます
- 理由と原則は [Shield.md](./Shield.md) にまとめています。「繋げば良くなる」わけではありません

## 初心者向けの注意

- **信号が小さい＝ノイズに弱い**。ケーブルは短く、動力線と並べて這わせないこと
- 値が「-1」やずっと同じ数字で固まる → 配線ミスかロードセル未接続を疑う
- 増幅前後どちらもアナログなので、**必ず校正が必要**です（→ [Calibration.md](./Calibration.md)）
- ±どちらにも振れます。引張／圧縮で符号が逆になるだけなので、係数の符号で合わせます
- 変換速度が10回/秒なので、それより速い現象は追えません
- readyの通知（DOUT Low）を受けたら**すぐ読む**こと。遅れて次周期に被ると不定値になります
- **DC励起**なのでゼロ点がゆっくり動きます。Tareで吸収する前提で使ってください（→ [Excitation.md](./Excitation.md)）
- ロードセル自体の説明は [LoadCell.md](./LoadCell.md)、中身のブリッジは [StrainGauge.md](./StrainGauge.md) を参照
