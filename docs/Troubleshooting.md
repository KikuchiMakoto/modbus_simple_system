# 困ったときは

上から順に確認してください。ほとんどはここで解決します。

## 接続まわり

**ブラウザにポートが出てこない**

- Chrome / Edge を使っているか（Safari・Firefoxは非対応）
- USBケーブルが「充電専用」でないか（データ線のあるものが必要）
- Arduino IDEのシリアルモニタなど、他のソフトがCOMポートを開いていないか

**接続できるが値が来ない**

- ファームウェアが書き込まれているか（→ [Arduino.md](./Arduino.md)）
- 書き込み時のボード選択が **Arduino Nano R4** になっていたか
- 通信設定は 38400bps / スレーブID 1（→ [ModbusRTU.md](./ModbusRTU.md)）

## 値がおかしい

| 症状 | 疑うところ |
| --- | --- |
| ずっと0、または同じ値で固まる | センサー未接続・配線ミス |
| グラフが平らで頭打ち | 入力レンジ超過（→ [ADS1115.md](./ADS1115.md)） |
| 数値がふらつく | GND未接続、ケーブルが長い・動力線と並走、シールドの両端接地（→ [Shield.md](./Shield.md)） |
| 力と逆向きに動く | 信号線の＋−が逆。係数の符号でも直せます |
| kgやNにならない | 校正がまだ（→ [Calibration.md](./Calibration.md)） |
| 特定のICだけ読めない | I2Cアドレス重複（→ [I2C.md](./I2C.md)） |

## 出力が出ない

- GP8403のI2Cアドレス設定を確認（→ [GP8403.md](./GP8403.md)）
- 出力先とGNDが共通になっているか
- ホールディングレジスタに書く値は **mV単位**（10V＝`10000`）

## それでも直らないとき

1. エラーメッセージ・症状・写真を、そのまま生成AIに貼って切り分ける
2. 各リポジトリのREADMEとWikiを確認する
3. それでも残る問題は Issue へ

> 🔰 「どこまで動いて、どこから動かないか」を先に切り分けると、質問もIssueも一気に解決しやすくなります。
