# GP8403とは
校正無しで10V出力可能なアナログ出力器（DAC）である。

4096段階（12bit）の分解能があります。

20mA程度は確実に出力できるので、多くの装置に確実にアナログ信号を送れます。
　
（内部的には50から100kHzのPWM出力と基準電圧を持ったコンパレータ回路と思われます）

## ざっくり仕様

| 項目 | 内容 |
| --- | --- |
| 出力 | 2ch／IC |
| 出力範囲 | 0〜5V または 0〜10V（設定で切替） |
| 分解能 | 12bit（4096段階） |
| 接続 | I2C（→ [I2C.md](./I2C.md)） |

本システムでは **AO0〜AO7** の8chがGP8403です（IC 4個 × 2ch、0〜10V設定）。

## 使い方

Modbusのホールディングレジスタ0〜7に、出したい電圧を**mV単位**で書くだけです。

| 書く値 | 出る電圧 |
| --- | --- |
| 0 | 0V |
| 2500 | 2.5V |
| 10000 | 10V |

計測アプリのPython（Pyodide）からは `SetAo()` で同じことができます。

## 初心者向けの注意

- **I2Cアドレスを基板ごとに設定する**必要があります（4段階）。4個とも同じだと1個しか動きません
- 0〜10V設定でも、供給電圧が足りないと10Vまで上がりません。電源を確認
- 出力先とGNDを共通にすること。GNDが別だと相手側で正しい電圧になりません
- 電流を取りすぎる負荷（低いインピーダンス）につなぐと電圧が落ちます。20mAが目安
