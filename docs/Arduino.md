# Arduinoとは

マイコンボードと、その開発環境（Arduino IDE）をまとめた呼び名です。

C++に近い言語でプログラム（スケッチ）を書き、USBケーブルで書き込むだけで動きます。回路や組み込みの知識がなくても始められるのが最大の利点です。

## 用語：ソフト？アプリ？ファームウェア？

同じ「プログラム」なのに呼び名が違うのは、**動く場所が違う**からです。

| 呼び名 | どこで動く | 例 |
| --- | --- | --- |
| ソフト・アプリ | パソコンやスマホの上 | 計測アプリ（modbus_simple_logger） |
| **ファームウェア** | **機器（マイコン）の中** | modbus_simple_firmware |

ファームウェア（firmware）は、**hard（硬い＝回路）と soft（柔らかい＝ソフト）の中間**という意味の造語です。

- 電源を切っても消えず、機器の中に残り続ける
- 機器の動作そのものを決める＝**書き換えれば別物になる**
- 家電やルーターの「ファームウェアアップデート」も同じ意味

つまり本システムでは、**基板の振る舞いを決めているのがファームウェア**、パソコン側で見る画面がアプリ、という関係です。

## 覚える言葉は3つだけ

| 言葉 | 意味 |
| --- | --- |
| **スケッチ** | Arduinoでの「プログラム（ソースコード）」の呼び名。絵を描くように気軽に、という由来。拡張子は `.ino` |
| **ライブラリ** | 誰かが作った部品集。難しい処理を肩代わりしてくれる |
| **Arduino IDE** | 書く・変換する・書き込む、を1つでこなすソフト |

**Arduino IDE** の中身も、実は4つの機能だけです。

- エディタ：スケッチを書く
- 検証（コンパイル）：人が読む文字を、マイコンが読む機械語（`.bin`）に変換する
- 書き込み：その `.bin` をUSB経由でマイコンへ転送する
- シリアルモニタ：マイコンからの文字を見る

「ボードマネージャ」で使うボードの種類を、「ライブラリマネージャ」で部品集を追加します。

## プログラムの基本形

```cpp
void setup() {   // 電源投入時に1回だけ実行
  Serial.begin(38400);
}

void loop() {    // 以後ずっと繰り返し実行
  Serial.println("hello");
  delay(1000);
}
```

`setup()` で初期設定、`loop()` で本体処理。この2つを覚えれば読めます。

## ライブラリ

センサーICごとの面倒な通信手順は「ライブラリ」が肩代わりします。IDEの「ライブラリマネージャ」から名前で検索して追加します。

本システムで使うのは HX711 Arduino Library / ADS1115_WE / DFRobot_GP8403 / ModbusRTUSlave の4つです。

## 書き込み

1. ボードとPCをUSBで接続
2. IDEで「ボード」＝ Arduino Nano R4、「ポート」＝ 表示されたCOMポートを選択
3. 「→」（書き込み）ボタンを押す

ビルド済みファイル（`.bin`）を書き込むだけなら、[はじめてガイド](./GettingStarted.md) のPowerShell 1行で終わります。

## つまずいたら

- ポートが出ない → USBケーブルが「充電専用」でないか確認（データ線のあるものが必要）
- 書き込み失敗 → 他のソフトがCOMポートを開いていないか確認。書き込み時のリセットの仕組みは [USBCDC.md](./USBCDC.md)
- 直らない → エラーメッセージをそのまま生成AIに貼るのが最短です
