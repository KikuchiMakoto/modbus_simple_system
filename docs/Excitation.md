# DC励起とAC励起

ブリッジに掛ける電源（励起）を、直流にするか交流にするかの話です。ひずみ測定器の性格はここで決まります。

## DC励起（HX711はこちら）

一定の直流をブリッジに掛け、出てきた直流をそのまま増幅します。

- 回路が単純・安価・小さい
- 応答が速く、扱いも簡単

弱点は、**誤差も直流で入ってくる**こと。信号と区別がつきません。

- 熱起電力：異種金属の接点で生じる数μVの直流。温度差でふらつく
- アンプのオフセットとその温度ドリフト、低周波（1/f）ノイズ
- ケーブルの湿気・絶縁劣化による漏れ

対策は運用側で：**測定直前にTare**、ケーブルは短く、電源を入れて温度が落ち着いてから測る。

## AC励起（搬送波型）

数kHzの交流でブリッジを励起し、返ってきた信号を **同期検波（位相敏感検波）** で元に戻します。

信号は搬送波の周波数に乗って運ばれるので、**その周波数にない成分＝直流のズレは復調時に全部落ちます**。

- 熱起電力・アンプオフセット・ドリフトに強い
- 狭い帯域だけ見るのでノイズにも強い
- 長時間の微小ひずみ測定（クリープ試験など）で威力を発揮

弱点：

- 回路が複雑で高価
- 測れる速さが搬送波に縛られる（目安：搬送波周波数の1/10程度まで）
- ケーブル長・容量で位相がずれるため、調整（バランス取り）が必要

## 励起電圧は高いほど良い、ではない

出力は `mV/V × 励起電圧` なので、電圧を上げれば信号は素直に大きくなります。ではなぜ上げないのか。**熱になるから**です。

ブリッジは抵抗の塊なので、掛けた電圧の分だけ電流が流れて発熱します。

| 励起電圧 | 350Ωブリッジの電流 | 消費電力 |
| --- | --- | --- |
| 4.2V（HX711） | 12mA | 約50mW |
| 5V | 14mA | 約71mW |
| 10V | 29mA | 約286mW |

この熱は、**ゲージを貼った金属片の内部**で発生します。小さなロードセルほど逃げ場がありません。

- 温まると寸法が変わり、**ゼロ点がじわじわ動きます**（ドリフト・クリープの主因）
- 熱が安定するまで測れない＝ウォームアップ時間が延びます
- ひどいと接着剤が劣化し、ゲージが剥がれます

> ⚠️ **必ず使うセンサーの仕様書を確認してください。** 「推奨励起電圧」「最大励起電圧」が必ず書いてあります。120Ωブリッジや小型のロードセルは熱がこもりやすいので、低めに抑えるのが定石です。

**本システムは [HX711](./HX711.md) の4.2V固定**なので、この心配はありません。5Vや10Vを想定したセンサーでも、出力はmV/V（励起電圧に比例）なので、**校正で吸収されます**。低めの励起電圧は熱の面ではむしろ有利です。

## どちらを使うか

| 用途 | 向き |
| --- | --- |
| 数分〜数十分の試験、破断まで測る | DCで十分（**本システム**） |
| 数時間〜のクリープ試験、μSTレベルの微小ひずみ | AC励起の市販ひずみ測定器が有利 |
| LVDT・差動トランス式センサー | **AC必須**（→ [LVDT.md](./LVDT.md)） |

## 初心者向けの注意

- HX711はDC励起です。ゼロ点がゆっくり動くのは仕様の範囲。**Tareで吸収する**前提で使ってください
- 「値が数分かけてじわじわ動く」のは、故障ではなく温度ドリフトのことが多いです
- 精度が足りないと感じたら、まず配線とTareの運用を見直す。それでも足りなければAC励起の測定器を検討する順番です
