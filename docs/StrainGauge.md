# ひずみゲージとブリッジ

ロードセルの中身です。ここを知っておくと「2.0mV/V」の意味が腑に落ちます。

## ひずみとμST（マイクロストレイン）

ひずみ ε は「元の長さに対して何割伸びたか」。単位はありません。

```
ε = ΔL / L
```

小さすぎて扱いにくいので、100万分の1を1単位にした **μST（マイクロストレイン）** を使います。

- 1 μST ＝ 1×10⁻⁶ ＝ 0.0001%
- 1mの棒が **1μm** 伸びたら 1μST
- 鉄鋼の弾性範囲はだいたい **〜2000μST**
- ロードセルは定格荷重で **1000μST前後**になるよう設計されています

## ゲージ率（ゲージファクタ）

ひずみゲージは、伸びると抵抗がわずかに増える金属箔です。

```
ΔR / R = K × ε      K（ゲージ率）≒ 2.0
```

1000μST でも抵抗変化は **0.2%** だけ。350Ωなら0.7Ωです。この程度の変化を直接測るのは難しいので、ブリッジ回路を使います。

## ブリッジ回路

4本の抵抗をひし形に組み、対角に電圧を掛けて、残りの対角から差を取り出します。**バランスしていれば出力0**なので、変化分だけを取り出せます。

| 構成 | 使うゲージ | 出力（1000μST・K=2） | 温度補償 |
| --- | --- | --- | --- |
| 1/4ブリッジ | 1枚 | 0.5 mV/V | ×（ダミーゲージが必要） |
| 1/2ブリッジ | 2枚 | 1.0 mV/V | △ |
| **フルブリッジ（4ゲージ）** | 4枚 | **2.0 mV/V** | ○ |

## なぜロードセルは2.0mV/Vなのか

フルブリッジ（引張側2枚・圧縮側2枚）では、出力がそのまま `K × ε` になります。

```
K = 2.0、ε = 1000μST = 0.001
→ 出力 = 2.0 × 0.001 = 0.002 = 2.0 mV/V
```

カタログでよく見る 2.0mV/V は、**「定格荷重でおよそ1000μST」という設計の裏返し**です。

## フルブリッジが選ばれる理由

- 出力が1/4ブリッジの4倍
- 4枚が同じ温度で同じだけ抵抗変化するので、**温度の影響が打ち消される**
- 貼る向きを工夫すると、曲げやねじれの成分をキャンセルできる

## 初心者向けの注意

- 市販ロードセルは4線出てくればフルブリッジ完成品です。中身を意識せず使えます
- ブリッジ抵抗は 350Ω が主流。120Ω は電流が増えて自己発熱しやすくなります
- 出力は μV〜mV の世界。配線・ノイズ対策が精度を決めます（→ [Excitation.md](./Excitation.md)）
