# センサー接続早見表

「手元にあるセンサーを、どの入力に繋げばいいか」を1ページにまとめました。詳細は各ページへ。

## まず出力の型を確認する

センサーの**仕様書に書かれた出力の型**で接続先が決まります。型名（LVDTなど）やメーカーではなく、**出力仕様**で判断してください。

| 出力の型 | 接続先 | 条件・注意 | 詳細 |
| --- | --- | --- | --- |
| **mV/V**（ひずみゲージ式・4線） | [HX711](./HX711.md) 側 **AI0〜7** | 4線フルブリッジ。シールドはE−へ片側接地 | [StrainGauge](./StrainGauge.md) |
| **0〜5V** 電圧 | [ADS1115](./ADS1115.md) 側 **AI8〜15** | GND共通必須。そのまま入る | [ADS1115](./ADS1115.md) |
| **0〜10V** 電圧 | AI8〜15 | **分圧は最終手段**。絶縁形変換器（0〜10V→0〜5V）を推奨 | [ADS1115](./ADS1115.md) |
| ±10V 電圧 | AI8〜15 | マイナス不可。単極性（0〜10V）機種を選ぶのが楽 | [Signals](./Signals.md) |
| **4〜20mA** 電流 | AI8〜15 | ⚠️ **直結禁止**。絶縁形ディストリビュータ経由で固定 | [CurrentLoop](./CurrentLoop.md) |
| **トランス式LVDT**（mV/mm・○○Hz励起） | AI8〜15 | **市販AC励起アンプ経由で固定**。自作しない | [LVDT](./LVDT.md) |

> 🔰 判断に迷ったら：出力が mV/V なら HX711 側。V 単位や mA 単位なら ADS1115 側、です。

## よくあるセンサーごとの対応

| センサー | 典型的な出力 | 接続先 | 備考 |
| --- | --- | --- | --- |
| ロードセル | 2.0mV/V | AI0〜7 | [ロードセル](./LoadCell.md)。校正必須 |
| ひずみゲージ式 変位計・クリップゲージ | mV/V | AI0〜7 | 「LVDT」と呼ばれていても実体はこちらのことが多い（→ [LVDT](./LVDT.md) 冒頭の注意） |
| 真のトランス式LVDT | AC出力 | AI8〜15（アンプ経由） | アンプ出力が4〜20mAなら [CurrentLoop](./CurrentLoop.md)、電圧なら [ADS1115](./ADS1115.md) の分圧規則 |
| 圧力計・流量計（産業用） | 4〜20mA | AI8〜15（変換器経由） | DC24Vが乗っている。直結禁止 |
| 温度（熱電対など） | μV〜mV級 | **非推奨** | 本システムは冷接点補償なし。専用ICか市販変換器の出力を受ける運用に |
| ポテンショメータ式変位計 | 0〜5V / 0〜10V | AI8〜15 | 10Vは分圧か変換器。接触式なので寿命あり |

## 接続時の共通ルール

1. **GNDは必ず共通にする**（→ [ADS1115](./ADS1115.md)）。ただしシールドとアースは別物（→ [Shield](./Shield.md)）
2. **シールドは受け側の1点だけ**接地。本システムなら HX711 の E−
3. ケーブルは短く、動力線と並べない（→ [Shield](./Shield.md)）
4. 繋いだら**必ず校正**してから測る（→ [Calibration](./Calibration.md)）
5. 値がおかしいときは [困ったときは](./Troubleshooting.md) → センサー故障の切り分けへ

## 学習の順番（はじめての方へ）

[はじめてガイド](./GettingStarted.md) の「センサー優先」方針に沿った読み進め方です。

```
① 自分のセンサーの出力型を確認（このページの表）
② ひずみゲージ系なら StrainGauge → LoadCell → HX711 の順
③ 電圧・電流系なら ADS1115 → CurrentLoop の順
④ 励振の話は Excitation（DC/ACの違いと発熱）
⑤ 繋げたら Calibration で校正
```
