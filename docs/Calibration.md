# キャリブレーション（校正）とTare

センサーが返すのは「生の数値」です。これを **N・kg・mm といった物理量に翻訳する作業**が校正です。

## 計測アプリの変換式

チャネルごとに、次の2次式の係数を設定します。

```
物理値 = a·x² + b·x + c        （x は生データ）
```

- ほとんどのセンサーは直線なので **a = 0、b と c だけ**でOK
- b＝傾き（1カウントあたり何N か）、c＝オフセット（ゼロ点）
- 曲がりがある場合だけ a を使います

## 校正のやり方（2点法）

1. 何も掛けない状態の生データを読む → `x0`
2. 既知の重り（例：10kg）を掛けた生データを読む → `x1`
3. `b = 10 / (x1 - x0)`、`c = -b · x0`
4. アプリに b と c を入力し、重りを載せ直して10kgと出れば成功

精度が要るときは3点以上取り、直線からのズレを確認します。

## 本気で校正するなら（多点・往復法）

2点法は「とりあえず動かす」ための最短ルートです。**本気でキャリブレーションするなら**、以下を守ってください。

- **フルレンジに対して5点以上**取る（0%・25%・50%・75%・100%など）
- **3往復**する（載せて外してを3回繰り返す）
- **除荷時（荷重を外していく側）も測る。** 載せるときだけでなく、外すときの値も記録してください

なぜ往復・除荷まで見るのか。**載せたときは直線に見えても、外したときに元の位置（x0）へ戻らないセンサーがあります。** これは弾性域を超えて**塑性変形**した証拠です。載荷側だけの測定では気づけません。

### なぜ「普通は直線」なのか

加速度計や[LVDT](./LVDT.md)などを除いた、**ひずみゲージ系のセンサー（ロードセルなど）は基本的に線形出力**です。これはひずみが `a·x + b` で表せる**線形領域（弾性領域）**だけを使うよう設計されているからです。詳しくは → [StrainGauge.md](./StrainGauge.md) を読んでください。

だからこそ、この式の `a·x² + b·x + c` の **a（曲がりの成分）は、普通は0のはずです。**

> ⚠️ **多点で校正して、無視できないほど大きな a が出てきたら要注意です。** ひずみゲージ系センサーが線形領域を外れている、つまり以下のいずれかが起きた可能性があります。
>
> - 座屈
> - 水没
> - 変形
> - 漏電
> - 電気的破壊
> - 脆性破壊
> - 塑性変形
>
> `a` を無理やり係数に組み込んで帳尻を合わせるのではなく、**まずセンサー自体を疑ってください。**

## Tare（0点補正）

**その瞬間の値を0にする**機能です。ボタン1つで実行できます。地盤・材料試験の文脈では「風袋引き」と同じ操作です。

- 治具や容器の重さを引きたいとき
- 温度ドリフトでゼロが動いたとき
- 試験を開始する直前

校正（傾き）は変えず、オフセットだけをずらす操作だと考えてください。

## 初心者向けの注意

- **校正 → Tare の順**。校正をやり直すとTareは取り直しです
- 重りを載せる向き・位置は本番と同じにする。斜めだと値が変わります
- 値がふらついて決まらないときは、校正の前に配線とノイズを疑う（→ [HX711.md](./HX711.md)）
- 係数は必ずメモ or 保存。基板やセンサーを交換したら取り直しです
