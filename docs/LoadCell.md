# ロードセルとは

**力や重さを電圧に変えるセンサー**です。

金属の柱に「ひずみゲージ」を4枚貼り、力でわずかに伸び縮みする量を電気で読み取ります。

## 出力はとても小さい

カタログの `2.0 mV/V` は「電源1Vあたり、定格いっぱいの力で2.0mV出る」という意味です。

例：2.0mV/V・定格100kgのロードセルを [HX711](./HX711.md) につなぐと、給電は約4.2Vなので、100kg掛けても **約8.4mV** しか出ません。だから増幅が要ります。

HX711のゲイン128で測れるのは ±3.906mV/V まで。2.0mV/V のロードセルは**定格でも半分ちょっとしか使わない**、と覚えておくと選定が楽です。

## 選ぶときに見る数字

| 項目 | 意味 |
| --- | --- |
| 定格容量 | 測れる上限（例：100kg、5kN） |
| 定格出力 | mV/V。だいたい 1.0〜3.0 |
| 過負荷 | 壊れずに耐えられる上限（定格の120〜150%が多い） |
| 線数 | 4線式が一般的。6線式は長い配線でも精度が落ちにくい |

## 初心者向けの注意

- **定格の何倍もの力を掛けない**。一度曲げると元に戻りません
- 取り付けは「まっすぐ荷重が掛かる」ように。斜めやねじれは誤差になります
- 温度でゼロ点がゆっくり動きます。測定前にTare（0点補正）を取る習慣を
- 出力は力に比例しますが、**何kg／何Nかは校正しないと分かりません**（→ [Calibration.md](./Calibration.md)）
- 変位計など他の電圧出力センサーは、HX711ではなく [ADS1115](./ADS1115.md) 側（AI8〜15）につなぎます
