# LVDT（差動トランス式変位計）とは

コイルの中を鉄心（コア）が動くことで変位を測るセンサーです。**非接触**で測れるため、材料試験の変位計として定番です。

## しくみ（トランス方式）

名前の通り、中身は**トランス（変圧器）**です。

1次コイルに交流を流し、その外側の2次コイル2つに**逆向きに**電圧を誘起させます。

- コアが中央 → 2つの誘起電圧が等しく打ち消し合い、**出力ゼロ**
- コアがずれる → 差が出る。**振幅＝移動量、位相＝どちら向きか**

## だからAC励起が必須

トランスは、**磁束が変化しないと電圧を誘起できません**。直流を流しても、磁束は一定のままで何も起きない——つまり原理上、**直流では動きません**。

必ず交流で駆動し、出てきた交流を**復調（同期検波）して直流に戻す**回路が要ります（→ [Excitation.md](./Excitation.md)）。

## だから「市販のAC励起ひずみアンプ」を買う

このAC励起・復調の回路は、自分で作るものではありません。**LVDT用の信号変換器（ひずみアンプ／変位計アンプ）を買ってください。** LVDTメーカー純正品や、汎用の計測アンプメーカーから市販されています。

これを挟めば、アンプの出力側はただの**直流電圧**（または4〜20mA）になります。あとは普通のアナログ信号として扱えます。

```
[LVDT本体] ──交流──▶ [市販のAC励起アンプ] ──直流電圧──▶ [ADS1115 / AI8〜15]
              ここは自作しない・市販品を使う
```

出力電圧の受け方（分圧・レンジ）は [ADS1115.md](./ADS1115.md) を、出力が4〜20mAの機種なら [CurrentLoop.md](./CurrentLoop.md) を参照してください。**これらはLVDT固有の話ではなく、電圧入力・電流入力共通のルールです。**

> 🔰 中には発振・復調回路を内蔵し、直流電圧をそのまま出す「DC-DC型LVDT」もあります。これも中身はAC励起＋アンプが一体化しているだけで、考え方は同じです。

> 🔰 ひずみゲージ式のクリップ式伸び計（エクステンソメータ）なら、ブリッジなので **HX711側（AI0〜7）にそのまま入ります**。AC励起アンプが不要な分、本システムとは相性が良いです。

## 初心者向けの注意

- コアが可動範囲の端に来ると直線性が崩れます。**中央付近を使う**ようにセットする
- 本来は非接触ですが、芯出しがずれるとコアがボビン内壁に擦れます。値が暴れたら真っ先に確認する箇所です
- 変位が「向きだけ逆」なら、[校正](./Calibration.md)の係数の符号で合わせられます
