# シールドとアース、ケーブルまわり

微小信号を測るなら避けて通れない話です。そして、**繋げば良くなるとは限りません。**
ページ後半には、同軸ケーブル・BNC・「50Ω」の話もあります。

## まず、別物だと知る

同じ「GND」に見えて、役割が3つあります。混同すると必ず失敗します。

| 呼び方 | 目的 | 繋ぐ相手 |
| --- | --- | --- |
| **信号グラウンド** | 電圧を測る**基準の0V** | 回路どうし |
| **シールド** | 外来ノイズを**遮る筒** | 片側のグラウンド |
| **保護接地（アース／PE）** | **感電を防ぐ**ための大地への逃げ道 | 建屋のアース端子 |

安全のアースは、ノイズのためのものではありません。**信号を安全アースに落とすと、たいてい悪化します。**

## シールドは片側だけ繋ぐ

シールド線は、外側の網（編組）が信号線を筒状に囲んで、飛んでくる電界を遮る構造です。この網はどこかで0Vに落とさないと働きません。

**ただし、落とすのは片側だけです。**

```
○ 正しい：  センサー ────────[網]──────── 受け側 ┳ GND
                                                 ↑ここ1点だけ

× ダメ：    センサー ┳──────[網]──────── 受け側 ┳ GND
                     ↑両端で接地 → 網がループになる
```

両端を繋ぐと、網が1本の輪（**グラウンドループ**）になります。

- 離れた2点の大地電位は**必ず少し違います**。その差で網に電流が流れます
- 輪は磁界を拾うコイルでもあるので、**50/60Hzのハムを積極的に拾い込みます**
- 電位差が大きいと、網に無視できない電流が流れて発熱・誤差の原因になります

> **ノイズ対策のつもりで両端を繋いだ結果、ノイズが増える。** これが定番の失敗です。

## どちら側で落とすか

計測系では **受け側（アンプ側）の1点**が定石です。本システムなら [HX711](./HX711.md) の **E−** に落とします。

- センサー側が装置の金属フレームに触れている場合、そちら側は**浮かせる**（絶縁する）
- 迷ったら「輪を作らない方」を選んでください

## やってはいけないこと

- **シールドを信号の帰り線に使う**：4線式の A− と兼用しない。網に電流が流れた瞬間、ノイズが信号に化けます
- **あちこちで接地する**：接地点が増えるほどループが増えます。1点に集める（1点接地）
- **安全アースを外す**：ノイズが消えることがありますが、**絶対にやめてください**。感電します。信号側の繋ぎ方で解決すること

## 切り分けのコツ

ノイズが減らないときは、**シールドを一度外して比べてください。**

| 結果 | 原因 |
| --- | --- |
| 外したら減った | グラウンドループ。接地は片側だけに |
| 外したら増えた | シールドは効いている。別の原因を探す |
| 変わらない | シールドの問題ではない。配線長・電源・[励起方式](./Excitation.md)を疑う |

## 初心者向けの注意

- 動力線・インバータ・モーターの配線と**並べて這わせない**。交差させるなら直角に
- ケーブルは短く。余った分はとぐろを巻かず、8の字に折り返す（束ねるとコイルになります）
- 全装置のGNDを共通にするのは本システムの前提です（→ [ADS1115.md](./ADS1115.md)）。ただし共通にするのは**信号グラウンド**であって、アースやシールドではありません

## 同軸ケーブル・BNC・50Ω（計測器まわりの道具）

計測器の世界でよく見かける道具の話です。**知らずに真似すると損をする**ポイントがあります。

### 同軸ケーブルとBNC

同軸は芯線を絶縁体で包み、その外を網（シールド）で筒状に覆った構造。芯線が完全に囲まれているので**シールド効果が高い**のが特長です。外側の網はGNDに繋がります。

BNCコネクタは同軸を挿してひねるだけで着脱できるバヨネット式のコネクタで、オシロスコープ、チャージアンプ、加速度センサー、LVDTの変換器などで定番です。**外側の金属＝GND**なので、複数のBNC機器をつなぐとそこでGNDが共通化されます。

> ⚠️ 複数のBNC機器を繋ぐと、意図せず上記のグラウンドループができます。ノイズが増えたらここを疑ってください。

### 「50Ω」は抵抗値ではない

いちばん誤解されるところです。**テスターで測っても50Ωにはなりません**（芯線とシールドの間は絶縁されているので∞、芯線どうしはほぼ0Ω）。これは**特性インピーダンス**といって、「高周波の信号がケーブルを進むときの流れやすさ」を表す値です。送り出す機器・ケーブル・受ける機器の3つが揃っていないと信号が反射して波形が乱れます。

| 種類 | 主な用途 |
| --- | --- |
| 50Ω | 計測器・無線。オシロやRF機器はこちら |
| 75Ω | 映像・アンテナ |

### ただし、本システムでは関係ない

反射が問題になるのはナノ秒〜MHzの世界です。本システムが測るのは10回/秒のロードセルやゆっくり動く変位計で、**50Ωか75Ωかは実用上どうでもいい**話です。代わりに効いてくるのは:

- **ケーブルの静電容量**（同軸はおよそ100pF/m）。ハイインピーダンスの信号に長い同軸を使うと応答が鈍ります
- **長さ**。短いほど良い、は変わりません

基板側は**端子台（ネジ止め）**です。BNCで出てくる機器を繋ぐなら、BNC-端子台変換ケーブルか中継箱を用意することになります。圧着端子は専用工具で作業し、同軸を鋭角に曲げないでください。
