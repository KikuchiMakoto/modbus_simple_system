# I2Cとは

IC同士を **2本の線** でつなぐ通信方式です。「アイスクエアシー」「アイツーシー」と読みます。

| 線 | 役割 |
| --- | --- |
| SDA | データ |
| SCL | クロック（タイミング信号） |

この2本を数珠つなぎにするだけで、複数のICを同時にぶら下げられます。本システムでは [ADS1115](./ADS1115.md) と [GP8403](./GP8403.md) がI2Cです。

## アドレスがキモ

線を共有するので、ICごとに**住所（アドレス）**を割り当てて呼び分けます。

- アドレスはICのピンやジャンパで数種類から選べる
- **同じアドレスのICを2個つなぐと、両方おかしくなる**
- 本システムでは ADS1115 が2個、GP8403 が4個。それぞれ別アドレスに設定する必要があります

基板ごとの設定方法は [modbus_simple_pcb の Wiki](https://github.com/KikuchiMakoto/modbus_simple_pcb/wiki) を参照。

## プルアップ抵抗

SDA/SCLは電源側に抵抗で引き上げて（プルアップ）おかないと通信できません。

多くのモジュール基板には最初から載っています。ただし**モジュールを何枚も並列につなぐとプルアップが効きすぎて**通信が不安定になることがあります。

## 初心者向けの注意

- 動かないときは、まず「アドレス重複」「GND未接続」「配線の入れ替わり（SDA↔SCL）」の3つを疑う
- 配線は短く。数十cmを超えると不安定になりがちです
- 電圧を合わせること。本システムは全部5Vで統一しています
